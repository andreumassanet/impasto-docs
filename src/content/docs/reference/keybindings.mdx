**These are the defaults, read from the compositor's configuration.** Every key
belongs to a profile, so the keys on your machine are whatever the active
profile says: Settings → Keys changes any of them, and <kbd>SUPER</kbd> <kbd>H</kbd>
shows the ones in effect. The keys marked unbound can be given one there.
